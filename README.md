# Painel de Vendas — Black Friday 2026

Atelier Agulha e Pano.

Abra `index.html` no navegador para usar o painel. O sistema funciona sem servidor, com cadastro e edição de cursos, vendas, gráfico, cálculo de taxas e exportação CSV/backup JSON.

**Atenção:** os dados são salvos apenas no armazenamento local do navegador; não sincronizam entre dispositivos. Guarde backups JSON. Um repositório privado não significa que uma eventual página publicada no GitHub Pages esteja protegida por login.

Todos os valores de vendas começam zerados. Os preços iniciais são os valores informados da Black Friday e podem ser editados.
